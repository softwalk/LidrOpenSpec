# LidrOpenSpec

This repository contains the LIDR framework specifications and command documentation.

## Structure

- `ai-specs/`: Contains AI-related specifications
  - `.commands/`: Command specifications including commit commands
- `path/to/`: Example directory structure with sample files

## Documentation

See [commit.md](ai-specs/.commands/commit.md) for commit command specifications and best practices.

## Usage

This repository follows standard git workflow practices:
- Stage changes with `git add`
- Commit with meaningful messages using `git commit`
- Push to remote with `git push`

For detailed command specifications, refer to the documentation in the `ai-specs` directory.
